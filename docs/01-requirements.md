# 📋 需求规格文档 — Trail Gear

## 产品定位

一款面向徒步露营爱好者的装备管理与行程记录工具。核心亮点是**拍照自动抠图生成贴纸风格装备卡片**，让装备管理变得有趣且视觉愉悦。

**目标平台**：iOS + Android（Flutter 跨平台）

---

## 核心功能模块

### 模块一：装备柜（Gear Closet）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 添加装备 | 拍照或从相册选择 → 自动抠图 → 生成白色描边贴纸 | P0 |
| 装备信息 | 名称、品牌、型号、重量（克）、描述、分类 | P0 |
| 分类管理 | 庇护所、睡眠系统、厨具、穿戴、电子、消耗品等，支持自定义 | P0 |
| 装备浏览 | 贴纸卡片网格展示，按分类筛选 | P0 |
| 装备搜索 | 按名称、品牌关键词搜索 | P1 |
| 编辑/删除 | 修改装备信息，重新拍照，删除装备 | P0 |

### 模块二：行程记录（Trips）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 创建行程 | 行程名称、描述、开始/结束日期 | P0 |
| 打包清单 | 从装备柜中勾选本次要带的装备 | P0 |
| 打包状态 | 每个物品可标记"已打包 ✅"，出发前检查 | P0 |
| 重量统计 | 自动计算：基础重量 / 总重量 | P1 |
| 行程封面 | 可设置封面照片 | P1 |
| 行程历史 | 查看过去的行程和打包清单 | P0 |

### 模块三：贴纸工坊（Sticker Studio）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 自动抠图 | iOS Vision / Android ML Kit 设备端智能分割 | P0 |
| 白色描边 | 自动生成圆润的白色贴纸描边效果 | P0 |
| 预览确认 | 抠图结果预览，可重新拍照 | P0 |

### 模块四：用户系统

| 功能 | 描述 | 优先级 |
|---|---|---|
| 注册/登录 | 邮箱 + 密码，JWT 认证 | P0 |
| 数据同步 | 本地数据与云端双向同步 | P1 |

## 用户故事

### 添加装备
> 作为一个徒步爱好者，我想拍一张帐篷的照片，App 自动帮我把帐篷抠出来并加上白色描边变成好看的贴纸，我填上名称、品牌和重量，就加入了我的装备柜。

### 准备行程
> 作为一个即将出发的徒步者，我想创建一个新行程"武功山两日穿越"，然后从我的装备柜里勾选要带的装备，每收拾好一件就标记为"已打包"，确保不遗漏。

### 回顾行程
> 作为一个徒步完回来的用户，我想查看这次的打包清单，看看哪些东西带了但没用上，为下次行程做参考。
